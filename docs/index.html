A FEW THINGS TO KNOW
Does envRanger upload my secrets?
No. The CLI manages local files and has no telemetry or cloud sync. Normal reports contain key names and file paths. Explicit get --reveal prints values, and programs launched with run control their own output.
Can it overwrite an existing .env file?
Editing commands preview by default and require --write. Routes refuse conflicting values unless --overwrite is also supplied. Changed existing files are backed up locally. Each file is replaced atomically; multi-file routing is not a transaction.
Is this a secret vault?
envRanger encrypts local environment files using dotenvx and preserves their public keys. Private keys stay separate. It does not authenticate people or distribute secrets through a cloud vault. Use your secret manager or hosting provider to control who receives decryption keys.
What changed from the original version?
Version 0.3 adds dotenvx encryption and a shared loadEnv.js integration with explicit frontend, backend and root scopes. The core uses declarative JSON config, explicit profiles, safer file edits and tested routing. The experimental terminal wizard, vault wrappers and automatic hook installers have been removed. The guide includes a full migration table.
